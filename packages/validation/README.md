# @axion/validation — حي التحقق المركزي

> **الوعد:** «كل مدينة تُدخل بياناتها من بوابتي — تحقق موحد، ومخططات مركزية تحمي المدن التي لا تملك مخططاتها.»

## المعايير

- **OWASP Input Validation** — حدود، صيغ موحدة، أخطاء منظمة.
- **JSON Schema / OpenAPI 3.1** — عقود مولّدة آلياً (`contracts/`).
- **RFC 9457 Problem Details** — استجابات رفض موحدة.

## الأتمتة (الجيش الصامت)

```bash
npm install
npm test               # اختبارات الحي — البوابة
npm run generate:contracts   # توليد عقود OpenAPI
npm run check:contracts      # فحص انحراف العقود في CI
```

أي انحراف في العقود = بوابة حمراء. أي مدخل غير صالح = رفض تلقائي. لا تدخل بشري.
